Cyberbullying Detection Platform

Platform berbasis web yang menggabungkan model IndoBERT melalui FastAPI untuk membantu mendeteksi komentar cyberbullying pada konten YouTube secara lebih cepat dan terstruktur.

Kembali ke Portfolio Lihat Detail

Ringkasan Project

Proyek ini dibuat untuk menjembatani kebutuhan deteksi cyberbullying secara otomatis pada komentar YouTube yang banyak dipakai di era digital. Pengguna dapat menginput teks komentar lalu sistem akan memberikan hasil prediksi berdasarkan model yang sudah dilatih.

Peran Saya

  • Merancang alur aplikasi dan pengalaman pengguna
  • Membangun API layanan prediksi dengan FastAPI
  • Menghubungkan frontend dengan model machine learning
  • Menyiapkan struktur data dan dokumentasi proyek

Apa yang dibangun

Fitur utama yang dihadirkan

Deteksi komentar

Pengguna dapat memasukkan teks komentar dan melihat hasil prediksi secara langsung.

Model IndoBERT

Model NLP dipakai untuk memahami bahasa Indonesia dengan tingkat akurasi yang lebih baik.

Antarmuka yang sederhana

Desain web dibuat ringkas agar proses deteksi terasa cepat, jelas, dan mudah dipahami.
